### الخطوة 1: إعداد Backend (10 دقائق)

```bash
# 1. إنشاء حساب Supabase
# اذهب إلى https://supabase.com

# 2. إنشاء مشروع جديد
# اضغط New Project واملأ البيانات

# 3. تشغيل SQL Schema
# انسخ src/lib/supabase-schema.sql
# الصقه في SQL Editor واضغط Run

# 4. إعداد المصادقة
# فعّل Email provider في Authentication

# 5. إعداد التخزين
# أنشئ buckets: avatars, receipts, documents, videos

# 6. الحصول على المفاتيح
# انسخ Project URL و anon key من Settings > API
```

### الخطوة 2: إعداد Frontend (5 دقائق)

```bash
# 1. نسخ .env.example إلى .env
cp .env.example .env

# 2. ملء القيم في .env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGc...

# 3. تثبيت الاعتمادات
npm install

# 4. تشغيل التطبيق
npm run dev
```

### الخطوة 3: الاختبار (15 دقيقة)

```typescript
// 1. تسجيل مستخدم جديد
await supabase.auth.signUp({
  email: 'test@example.com',
  password: 'password123'
});

// 2. إنشاء لاعب
await supabase.from('players').insert({
  user_id: 'user-uuid',
  serial_number: 'SA-2014-FT-0001',
  // ...
});

// 3. تسجيل حضور
await supabase.from('attendance').insert({
  player_id: 'player-uuid',
  date: '2026-01-20',
  status: 'present'
});

// 4. إنشاء معاملة
await supabase.from('transactions').insert({
  player_id: 'player-uuid',
  amount: 500,
  type: 'subscription',
  status: 'pending'
});

// 5. اعتماد المعاملة (المدير المالي)
await approveTransaction('transaction-uuid', 'approver-uuid');
```

## 🔒 الأمان

### Row Level Security (RLS)
```sql
-- المستخدمون يرون بياناتهم فقط
CREATE POLICY "Users can view their own data" ON users
FOR SELECT USING (auth.uid() = id);

-- المدراء يرون كل شيء
CREATE POLICY "Admins can view all users" ON users
FOR SELECT USING (
  EXISTS (SELECT 1 FROM users WHERE id = auth.uid() AND role = 'admin')
);
```

### التحقق من الصلاحيات
```typescript
const { isAdmin, isCoach, isPlayer, isFinancial } = useAuth();

if (!isAdmin) {
  return <div>غير مصرح لك</div>;
}
```
