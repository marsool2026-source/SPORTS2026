## 🛠️ التقنيات المستخدمة

### Frontend
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - لغة البرمجة
- **Tailwind CSS 4** - إطار عمل CSS
- **Vite** - أداة البناء

### State Management
- **React Context** - إدارة الحالة العامة
- **useState/useEffect** - إدارة الحالة المحلية
- **Lazy Loading** - تحميل كسول للمكونات

### Charts & Analytics
- **Recharts** - رسوم بيانية تفاعلية
- **Custom Components** - مكونات مخصصة

### Design
- **Glassmorphism** - تأثيرات زجاجية
- **Gradient Colors** - تدرجات لونية
- **Animations** - حركات سلسة
- **RTL Support** - دعم اللغة العربية

### PWA
- **Manifest.json** - إعدادات التطبيق
- **Service Worker** - العمل بدون إنترنت
- **Offline Mode** - وضع عدم الاتصال

### Cross-Platform
- **Compatibility Layer** - طبقة توافق شاملة
- **StorageManager** - إدارة آمنة لـ localStorage
- **NotificationManager** - إدارة آمنة للإشعارات
- **PlatformDetector** - كشف المنصة
- **SafeAPI** - APIs آمنة مع fallbacks

## 🚀 التثبيت

### المتطلبات
- Node.js 18+
- npm أو yarn

### الخطوات

```bash
# استنساخ المشروع
git clone https://github.com/yourusername/sports-academy.git

# الدخول للمجلد
cd sports-academy

# تثبيت الحزم
npm install

# تشغيل التطوير
npm run dev

# البناء للإنتاج
npm run build
```
